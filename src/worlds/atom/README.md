# Inside the atom (`/e/<Symbol>/atom`)

The room behind every hall's big atom, for all 118 elements: its electron cloud from quantum mechanics.
How it works, the science and the traps: `docs/knowledge/inside-the-atom.md`.

| file | what |
|---|---|
| `inside.js` | the world: floor, cloud, nucleus to scale, the electron map, the camera, the arch back, the verse, the Atomling; what is shown and shared (`state`), the panels, the discoveries |
| `cloud.js` | the cloud drawn by marching rays through it at a reduced size (two views blended), and the photos' dots |
| `views.js` | what the cloud shows, from `src/chem/orbitals.js`: the whole atom (a table against log r), one subshell, one orbital; where each photo finds the electron; the blocks' colours |
| `board.js` | the electron map: a glass board drawn on a canvas, shells by shapes with Hund's boxes; `hit(uv)` says what a tap means |
| `camera.js` | the electron camera on its tripod: the flash, the shutter button |
| `words.js` | every word in English, European Portuguese, Polish and German, at both depths |
| `atom.test.js` | the words, every element's clouds, the photos |

The physics is in `src/chem/orbitals.js` (+ `orbitalSkins.js`, generated by `scripts/data/orbital_skins.mjs`),
tested by `src/chem/orbitals.test.js`. The panel's electron map is `src/ui/OrbitalMap.jsx`. The hall's door:
`src/worlds/atrium/atrium.js` (`intoAtom`); the address: `ATOM_ROOM` in `src/worlds/registry.js`.
