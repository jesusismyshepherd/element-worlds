# Element Worlds · Mundos dos Elementos

A 3D periodic table you can walk into. Every element is a cube on a night plaza; step inside and the
cube is bigger on the inside: a hall built from the element's data, and worlds designed for it
(walk through a carbon nanotube, stand above the clouds among oxygen molecules).

- `npm install`, then `npm run dev` (http://localhost:5310)
- `npm test` (data, atom model, collisions)
- `npm run data` rebuilds `src/data/elements.json` from `scripts/data/`

Data: PubChem periodic table (public domain) and the mendeleev package (MIT, numeric fields).
Read `CLAUDE.md` first, then `docs/design.md`.
